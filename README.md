# Cap Solver

**Cap Solver is a developer-focused toolkit for authorized testing of Cap CAPTCHA integrations.** It is intended only for systems you **own, operate, or have explicit written permission to assess**.

## Permitted Uses

Use Cap Solver only to:

- Test your own Cap CAPTCHA implementation
- Benchmark challenge reliability and difficulty
- Identify configuration weaknesses
- Improve abuse resistance
- Support responsible security research

## Prohibited Uses

Do **not** use Cap Solver to:

- Bypass CAPTCHA protections on third-party services
- Evade rate limits or anti-bot controls
- Automate account creation, scraping, spam, or abuse
- Access, test, or interact with systems without authorization
- Violate laws, terms of service, or platform policies

## Legal Notice

Cap Solver is provided solely for **defensive security testing, research, and educational purposes**. The maintainers do not authorize, support, or condone unauthorized CAPTCHA bypassing, abuse automation, scraping, spam, account farming, or evasion of anti-abuse systems.

Users are solely responsible for ensuring they have proper authorization and for complying with all applicable laws, regulations, contracts, and terms of service.
